Scrum transition quick reference

Our operating model for two Azure DevOps teams using TFVC, two-week sprints, lead review, UAT, and independent releases.

Lifecycle

Backlog→Refinement→Sprint Planning→Sprint→Development→TFVC Shelveset / Lead Review→UAT→Done→Release / Go Live→Retrospective

Ceremony cheat sheet

  • Refinement: clarify, split, estimate, and expose dependencies.
  • Planning: set a Sprint Goal and forecast work using capacity.
  • Daily Scrum: inspect progress and adapt within 15 minutes.
  • Review: demonstrate the increment and gather feedback.
  • Retrospective: choose 1–2 improvements to try next sprint.

Definition of Done

  • Acceptance criteria satisfied.
  • Code complete and work item associated.
  • TFVC shelveset lead review completed.
  • Correct check-in and build completed.
  • Required validation and UAT completed.
  • Board status is accurate.

Future goal: automated tests and CI. Unit tests are not a current required gate.
