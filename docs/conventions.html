Conventions

Consistency is a feature. Shared styles, predictable sections, and explicit Razor partials keep this reference site useful in production contexts.

Pattern page template

  • Hero and one-line summary
  • Why this matters in Razor Pages
  • Demo panel
  • How it works
  • Markup + handler + partial snippets

Code conventions

  • Prefer explicit handler names and explicit partials.
  • Keep JavaScript modules focused by concern.
  • Use CSS custom properties for palette and tone coherence.

Visual conventions

Use consistent card radius, shadow hierarchy, spacing rhythm, and integrated code block treatment across all pages.
