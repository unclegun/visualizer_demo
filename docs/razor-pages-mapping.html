HTMX + Razor Pages Mapping

Use HTMX where it complements Razor Pages partial rendering, not as a replacement for full application state management.

Core architecture to teach

  • Razor Pages owns routes and handler structure.
  • Partials own fragment markup.
  • HTMX owns transport and swap behavior.
  • Bootstrap owns visual primitives.
  • Custom JavaScript fills only true interaction gaps.

When to use HTMX

  • Search/filter partial updates
  • Forms inside modals
  • Dependent selects
  • Row actions and table refreshes
  • Lazy-loaded page fragments

When not to use HTMX as default

  • Full SPA-style state orchestration
  • Complex drag/drop stateful interfaces
  • Heavy client-side visualization builders

Anti-forgery and forms

Keep anti-forgery tokens in forms and include them in HTMX submissions. For server validation failures, return the same partial with validation summaries.

if (!ModelState.IsValid)
{
    return Partial("_EditUserForm", input);
}

Pattern implementation playbooks

  • HTMX Partials: input event -> handler -> partial list fragment -> target swap.
  • HTMX Modal Form: modal shell static -> body partial via GET -> POST same partial on errors.
  • Cascading Selects: parent ID in request -> server-authoritative child options fragment.
  • Table Refresh: post row action -> return row partial or tbody partial + OOB status.
  • Chart Dashboard: JSON data endpoint + isolated chart renderer module.

Recommended file layout for Razor Pages

Pages/Users/Index.cshtml
  Pages/Users/Index.cshtml.cs
  Pages/Users/_UserRow.cshtml
  Pages/Users/_UserEditForm.cshtml
  Pages/Users/_UserSearchResults.cshtml
  wwwroot/js/users-page.js

Shared handler conventions

public PartialViewResult Partial(string name, object model)
    => new PartialViewResult
    {
      ViewName = name,
      ViewData = new ViewDataDictionary(ViewData, model)
    };

Use consistent naming such as OnGetSearchAsync, OnGetEditFormAsync, and OnPostSaveAsync so teams can scan patterns quickly.

Operational guidance

  • Log handler timings for fragment endpoints separately from full-page loads.
  • Add integration tests for validation failure and success return paths.
  • Return 204 for successful modal saves when no HTML replacement is required.
  • Use HX-Trigger for page-level events instead of custom global JS buses.

Progressive enhancement mindset

Base HTML and server handlers should still represent the canonical workflow. HTMX enhances network and interaction flow without removing server authority.
