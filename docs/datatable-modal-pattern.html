Reusable v1 client-side DataTable + modal tag helper pattern

This page documents a lightweight, maintainable pattern for rendering model-driven tables with DataTables.js, row-click modal editing, shared styling, and minimal Razor markup. It is intentionally scoped for v1: client-side only, explicit edit partials, and a single reusable modal shell.

What this pattern solves

Use this as a template when you want repeatable, styled, low-boilerplate table pages in Razor Pages without prematurely building server-side processing or generic edit-form generation.

Section 1

Architecture overview

The v1 design stays deliberately small. Only the model attribute, two tag helper files, one JavaScript module, and one CSS file are needed.

1

Model attribute

DataTableColumnAttribute is the single source of table metadata. Only decorated properties are rendered. Everything else is ignored by default.

2

Rendering layer

DataTableTagHelper converts IEnumerable<T> into semantic table markup, emits column filter controls, row keys, and JSON configuration for the client module.

3

Interaction layer

app-ui.js initializes DataTables, wires filter inputs, maps row clicks to edit URLs, and handles AJAX modal form submit/refresh behavior.

4

Edit partial

The modal body is still an explicit partial. That keeps layout, validation, field grouping, and permission-sensitive UI under normal Razor control.

5

Styling ownership

custom-bootstrap.css holds all table and modal presentation. That avoids spreading component styling across generated markup, partials, and inline scripts.

Responsibility flow

DataTableColumnAttribute Defines included columns, order, filters, formatting, key column
DataTableTagHelper Renders semantic table markup and JSON config
app-ui.js Initializes DataTables, filters, row click, modal load, form submit
Edit partial + custom CSS Explicit form markup and shared visual styling

Section 3

Best practices and design notes

The tradeoffs are intentional. This v1 pattern favors clarity, repeatability, and low friction over maximal abstraction.

Why opt-in columns

Opt-in is safer than opt-out. Properties added later to the view model are ignored until someone explicitly marks them with DataTableColumn. That prevents accidental leakage of IDs, internal notes, permission flags, or audit fields.

Why explicit edit partials

Generated forms look attractive early but quickly become brittle. Explicit partials preserve field order, help text, grouping, validation, and custom widgets without turning the tag helper into a form builder framework.

Why client-side only is fine for v1

For admin pages, dashboard tables, and moderate list sizes, client-side DataTables keeps the first version simple. You get sorting, searching, paging, and filters immediately while deferring server-side processing until data volume actually requires it.

Why CSS belongs in custom-bootstrap.css

The tag helper should emit stable, semantic classes. Visual tuning belongs in one stylesheet so a front-end developer can restyle the component without editing C# rendering logic or rewriting markup generation.

Why one shared modal

One shared modal reduces DOM weight, avoids duplicated IDs, and keeps lifecycle logic consistent. The table row only supplies a key. The modal content is loaded on demand and replaced each time.

Why JavaScript stays in one file

Inline scripts do not scale across multiple pages. A single reusable module gives you one place to debug table behavior, modal flow, AJAX submission, and future enhancements.

B. DataTableTagHelper.cs

C# 
using System;
using System.Collections;
using System.Collections.Generic;
using System.Globalization;
using System.Linq;
using System.Reflection;
using System.Text;
using System.Text.Encodings.Web;
using System.Text.Json;
using Microsoft.AspNetCore.Mvc.Rendering;
using Microsoft.AspNetCore.Mvc.ViewFeatures;
using Microsoft.AspNetCore.Razor.TagHelpers;

namespace MyApp.TagHelpers;

[HtmlTargetElement("data-table", Attributes = ForAttributeName)]
public sealed class DataTableTagHelper : TagHelper
{
    private const string ForAttributeName = "asp-for";
    private static readonly JsonSerializerOptions JsonOptions = new(JsonSerializerDefaults.Web);
    private readonly HtmlEncoder _htmlEncoder;

    public DataTableTagHelper(HtmlEncoder htmlEncoder)
    {
        _htmlEncoder = htmlEncoder;
    }

    [HtmlAttributeName(ForAttributeName)]
    public ModelExpression For { get; set; } = default!;

    [HtmlAttributeName("table-id")]
    public string? TableId { get; set; }

    [HtmlAttributeName("page-size")]
    public int PageSize { get; set; } = 10;

    [HtmlAttributeName("edit-url-template")]
    public string? EditUrlTemplate { get; set; }

    [HtmlAttributeName("table-class")]
    public string TableClass { get; set; } = "table table-striped table-hover align-middle mb-0";

    [ViewContext]
    [HtmlAttributeNotBound]
    public ViewContext ViewContext { get; set; } = default!;

    public override void Process(TagHelperContext context, TagHelperOutput output)
    {
        var tableId = string.IsNullOrWhiteSpace(TableId)
            ? $"dt-{Guid.NewGuid():N}"
            : TableId;

        var modelType = For.ModelExplorer.ModelType;
        var elementType = GetElementType(modelType)
            ?? throw new InvalidOperationException($"{nameof(DataTableTagHelper)} requires IEnumerable<T>.");

        var rows = For.ModelExplorer.Model as IEnumerable
            ?? Array.Empty<object>();

        var columns = GetColumns(elementType);
        if (columns.Count == 0)
        {
            throw new InvalidOperationException(
                $"No properties on {elementType.Name} were decorated with {nameof(DataTableColumnAttribute)}.");
        }

        var keyColumn = columns.FirstOrDefault(column => column.Attribute.IsKey);
        var config = new
        {
            tableId,
            pageSize = NormalizePageSize(PageSize),
            editUrlTemplate = EditUrlTemplate,
            columns = columns.Select((column, index) => new
            {
                index,
                name = column.Property.Name,
                header = column.Attribute.Header ?? column.Property.Name,
                searchable = column.Attribute.Searchable,
                hidden = column.Attribute.Hidden,
                sortable = column.Attribute.Sortable,
                filterType = column.Attribute.FilterType
            })
        };

        output.TagName = "div";
        output.Attributes.SetAttribute("class", "app-datatable-wrapper");

        var builder = new StringBuilder();
        builder.AppendLine($"<table id=\"{_htmlEncoder.Encode(tableId)}\" class=\"{_htmlEncoder.Encode(TableClass)} app-datatable\">");
        builder.AppendLine("  <thead>");
        builder.AppendLine("    <tr>");

        foreach (var column in columns)
        {
            builder.Append("      <th");
            AppendHeaderAttributes(builder, column.Attribute);
            builder.Append('>');
            builder.Append(_htmlEncoder.Encode(column.Attribute.Header ?? column.Property.Name));
            builder.AppendLine("</th>");
        }

        builder.AppendLine("    </tr>");
        builder.AppendLine("    <tr class=\"app-datatable-filters\">");

        foreach (var column in columns)
        {
            builder.AppendLine("      <th>");
            builder.Append(BuildFilterMarkup(column.Attribute));
            builder.AppendLine("      </th>");
        }

        builder.AppendLine("    </tr>");
        builder.AppendLine("  </thead>");
        builder.AppendLine("  <tbody>");

        foreach (var row in rows)
        {
            var rowKey = keyColumn is null ? null : keyColumn.Property.GetValue(row)?.ToString();
            builder.Append("    <tr class=\"app-datatable-row\"");

            if (!string.IsNullOrWhiteSpace(rowKey))
            {
                builder.Append($" data-row-key=\"{_htmlEncoder.Encode(rowKey)}\"");
            }

            builder.AppendLine(">");

            foreach (var column in columns)
            {
                var rawValue = column.Property.GetValue(row);
                var textValue = FormatValue(rawValue, column.Attribute.Format);
                builder.Append("      <td");
                AppendCellAttributes(builder, column.Attribute);
                builder.Append('>');
                builder.Append(_htmlEncoder.Encode(textValue));
                builder.AppendLine("</td>");
            }

            builder.AppendLine("    </tr>");
        }

        builder.AppendLine("  </tbody>");
        builder.AppendLine("</table>");
        builder.AppendLine($"<script type=\"application/json\" class=\"app-datatable-config\" data-for=\"{_htmlEncoder.Encode(tableId)}\">{_htmlEncoder.Encode(JsonSerializer.Serialize(config, JsonOptions))}</script>");

        output.Content.SetHtmlContent(builder.ToString());
    }

    private static Type? GetElementType(Type modelType)
    {
        if (modelType.IsArray)
        {
            return modelType.GetElementType();
        }

        var enumerableType = modelType
            .GetInterfaces()
            .Append(modelType)
            .FirstOrDefault(type => type.IsGenericType && type.GetGenericTypeDefinition() == typeof(IEnumerable<>));

        return enumerableType?.GetGenericArguments()[0];
    }

    private static List<ColumnDefinition> GetColumns(Type elementType)
    {
        return elementType
            .GetProperties(BindingFlags.Instance | BindingFlags.Public)
            .Select(property => new ColumnDefinition(property, property.GetCustomAttribute<DataTableColumnAttribute>()))
            .Where(column => column.Attribute is not null)
            .Select(column => new ColumnDefinition(column.Property, column.Attribute!))
            .OrderBy(column => column.Attribute.Order)
            .ThenBy(column => column.Attribute.Header ?? column.Property.Name)
            .ToList();
    }

    private static int NormalizePageSize(int pageSize)
        => pageSize is 10 or 25 or 50 ? pageSize : 10;

    private static string BuildFilterMarkup(DataTableColumnAttribute attribute)
    {
        if (!attribute.Searchable)
        {
            return "<span class=\"app-datatable-filter-placeholder\">&nbsp;</span>";
        }

        if (string.Equals(attribute.FilterType, "select", StringComparison.OrdinalIgnoreCase))
        {
            return "<select class=\"form-select form-select-sm app-column-filter\"><option value=\"\">All</option></select>";
        }

        return "<input type=\"search\" class=\"form-control form-control-sm app-column-filter\" placeholder=\"Filter...\" />";
    }

    private static void AppendHeaderAttributes(StringBuilder builder, DataTableColumnAttribute attribute)
    {
        var classes = new List<string>();
        if (attribute.Hidden)
        {
            classes.Add("d-none");
        }
        if (!string.IsNullOrWhiteSpace(attribute.CssClass))
        {
            classes.Add(attribute.CssClass);
        }

        if (classes.Count > 0)
        {
            builder.Append($" class=\"{string.Join(" ", classes)}\"");
        }

        if (!string.IsNullOrWhiteSpace(attribute.Width))
        {
            builder.Append($" style=\"width:{attribute.Width}\"");
        }
    }

    private static void AppendCellAttributes(StringBuilder builder, DataTableColumnAttribute attribute)
    {
        var classes = new List<string>();
        if (attribute.Hidden)
        {
            classes.Add("d-none");
        }
        if (!string.IsNullOrWhiteSpace(attribute.CssClass))
        {
            classes.Add(attribute.CssClass);
        }

        if (classes.Count > 0)
        {
            builder.Append($" class=\"{string.Join(" ", classes)}\"");
        }
    }

    private static string FormatValue(object? rawValue, string? format)
    {
        if (rawValue is null)
        {
            return string.Empty;
        }

        if (rawValue is bool boolValue)
        {
            return boolValue ? "Yes" : "No";
        }

        if (!string.IsNullOrWhiteSpace(format) && rawValue is IFormattable formattable)
        {
            return formattable.ToString(format, CultureInfo.InvariantCulture);
        }

        return Convert.ToString(rawValue, CultureInfo.InvariantCulture) ?? string.Empty;
    }

    private sealed record ColumnDefinition(PropertyInfo Property, DataTableColumnAttribute Attribute);
}

using System.Threading.Tasks;
using Microsoft.AspNetCore.Razor.TagHelpers;

namespace MyApp.TagHelpers;

[HtmlTargetElement("app-modal")]
public sealed class AppModalTagHelper : TagHelper
{
    [HtmlAttributeName("id")]
    public string Id { get; set; } = "sharedModal";

    [HtmlAttributeName("size")]
    public string Size { get; set; } = "lg";

    [HtmlAttributeName("dialog-class")]
    public string? DialogClass { get; set; }

    public override async Task ProcessAsync(TagHelperContext context, TagHelperOutput output)
    {
        var childContent = await output.GetChildContentAsync();
        var dialogSizeClass = Size switch
        {
            "sm" => "modal-sm",
            "xl" => "modal-xl",
            _ => "modal-lg"
        };

        output.TagName = "div";
        output.Attributes.SetAttribute("id", Id);
        output.Attributes.SetAttribute("class", "modal fade app-modal-wrapper");
        output.Attributes.SetAttribute("tabindex", "-1");
        output.Attributes.SetAttribute("aria-hidden", "true");
        output.Content.SetHtmlContent($@"
<div class=\"modal-dialog modal-dialog-centered {dialogSizeClass} {DialogClass}\">
    <div class=\"modal-content app-modal-content\">
        {childContent.GetContent()}
    </div>
</div>");
    }
}

D. app-ui.js

JavaScript 
window.AppUi = (function ($) {
    "use strict";

    const selectors = {
        table: ".app-datatable",
        config: ".app-datatable-config",
        filter: ".app-column-filter",
        modal: "#entityEditModal",
        modalBody: "[data-modal-body]"
    };

    function initialize() {
        initializeDataTables();
        initializeModalForms(document);
    }

    function initializeDataTables() {
        document.querySelectorAll(selectors.table).forEach((table) => {
            const config = readConfig(table.id);
            if (!config || typeof $.fn.DataTable !== "function") {
                return;
            }

            const dataTable = $(table).DataTable({
                paging: true,
                searching: true,
                ordering: true,
                info: true,
                responsive: false,
                pageLength: config.pageSize || 10,
                lengthMenu: [[10, 25, 50], [10, 25, 50]],
                orderCellsTop: true,
                columnDefs: config.columns.map((column) => ({
                    targets: column.index,
                    searchable: column.searchable,
                    visible: !column.hidden,
                    orderable: column.sortable
                })),
                dom: "<'row align-items-center g-3 mb-3'<'col-md-6'f><'col-md-6 text-md-end'l>>t<'row align-items-center g-3 mt-3'<'col-md-5'i><'col-md-7 d-flex justify-content-md-end'p>>"
            });

            wireColumnFilters(table, dataTable, config);
            wireClickableRows(table, config);
        });
    }

    function readConfig(tableId) {
        const node = document.querySelector(`${selectors.config}[data-for='${tableId}']`);
        return node ? JSON.parse(node.textContent) : null;
    }

    function wireColumnFilters(table, dataTable, config) {
        const filterInputs = table.querySelectorAll(selectors.filter);
        filterInputs.forEach((input, index) => {
            const columnConfig = config.columns[index];
            if (!columnConfig || !columnConfig.searchable) {
                input.disabled = true;
                return;
            }

            if (columnConfig.filterType === "select") {
                populateSelectFilter(input, dataTable.column(index).data().toArray());
                input.addEventListener("change", () => {
                    const value = input.value;
                    dataTable.column(index).search(value ? `^${escapeRegex(value)}$` : "", true, false).draw();
                });
                return;
            }

            input.addEventListener("input", () => {
                dataTable.column(index).search(input.value).draw();
            });
        });
    }

    function populateSelectFilter(select, values) {
        const uniqueValues = [...new Set(values
            .map((value) => String(value).replace(/<[^>]+>/g, "").trim())
            .filter(Boolean))].sort();

        uniqueValues.forEach((value) => {
            const option = document.createElement("option");
            option.value = value;
            option.textContent = value;
            select.appendChild(option);
        });
    }

    function wireClickableRows(table, config) {
        if (!config.editUrlTemplate) {
            return;
        }

        table.querySelectorAll("tbody tr[data-row-key]").forEach((row) => {
            row.classList.add("app-clickable-row");
            row.addEventListener("click", (event) => {
                if (event.target.closest("a, button, input, select, textarea, label")) {
                    return;
                }

                const rowKey = row.dataset.rowKey;
                if (!rowKey) {
                    return;
                }

                const url = config.editUrlTemplate.replace("__id__", encodeURIComponent(rowKey));
                openEditModal(url);
            });
        });
    }

    async function openEditModal(url) {
        const modalElement = document.querySelector(selectors.modal);
        if (!modalElement) {
            return;
        }

        const modalBody = modalElement.querySelector(selectors.modalBody);
        modalBody.innerHTML = `
Loading...
`;

        const modal = bootstrap.Modal.getOrCreateInstance(modalElement);
        modal.show();

        const response = await fetch(url, {
            headers: {
                "X-Requested-With": "XMLHttpRequest"
            }
        });

        modalBody.innerHTML = await response.text();
        initializeModalForms(modalElement);
    }

    function initializeModalForms(root) {
        root.querySelectorAll("form[data-modal-form]").forEach((form) => {
            if (form.dataset.bound === "true") {
                return;
            }

            form.dataset.bound = "true";
            form.addEventListener("submit", async (event) => {
                event.preventDefault();

                const submitButton = form.querySelector("button[type='submit']");
                if (submitButton) {
                    submitButton.disabled = true;
                }

                const response = await fetch(form.action, {
                    method: form.method || "POST",
                    body: new FormData(form),
                    headers: {
                        "X-Requested-With": "XMLHttpRequest"
                    }
                });

                if (submitButton) {
                    submitButton.disabled = false;
                }

                const modalElement = form.closest(".modal");
                const modalBody = modalElement.querySelector(selectors.modalBody);
                const contentType = response.headers.get("content-type") || "";

                if (response.ok && contentType.includes("application/json")) {
                    const result = await response.json();
                    if (result.success) {
                        bootstrap.Modal.getInstance(modalElement)?.hide();
                        window.location.reload();
                        return;
                    }
                }

                modalBody.innerHTML = await response.text();
                initializeModalForms(modalElement);
            });
        });
    }

    function escapeRegex(value) {
        return String(value).replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
    }

    document.addEventListener("DOMContentLoaded", initialize);

    return {
        initialize,
        openEditModal
    };
})(window.jQuery);

C# 
using System;
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks;
using Microsoft.AspNetCore.Mvc;
using Microsoft.AspNetCore.Mvc.RazorPages;
using Microsoft.AspNetCore.Mvc.ViewFeatures;

namespace MyApp.Pages.Users;

public sealed class UsersModel : PageModel
{
    private readonly IUserService _userService;

    public UsersModel(IUserService userService)
    {
        _userService = userService;
    }

    public IReadOnlyList<UserTableRowViewModel> Users { get; private set; } = Array.Empty<UserTableRowViewModel>();

    [BindProperty]
    public EditUserInputModel Input { get; set; } = new();

    public async Task OnGetAsync()
    {
        Users = await LoadUsersAsync();
    }

    public async Task<PartialViewResult> OnGetEditModalAsync(Guid id)
    {
        var user = await _userService.GetForEditAsync(id);
        Input = new EditUserInputModel
        {
            Id = user.Id,
            Username = user.Username,
            Email = user.Email,
            Role = user.Role,
            Active = user.Active
        };

        return new PartialViewResult
        {
            ViewName = "_EditUserForm",
            ViewData = new ViewDataDictionary<EditUserInputModel>(ViewData, Input)
        };
    }

    public async Task<IActionResult> OnPostEditAsync()
    {
        if (!ModelState.IsValid)
        {
            return new PartialViewResult
            {
                ViewName = "_EditUserForm",
                ViewData = new ViewDataDictionary<EditUserInputModel>(ViewData, Input)
            };
        }

        await _userService.UpdateAsync(new UpdateUserRequest
        {
            Id = Input.Id,
            Username = Input.Username,
            Email = Input.Email,
            Role = Input.Role,
            Active = Input.Active
        });

        return new JsonResult(new { success = true });
    }

    private async Task<IReadOnlyList<UserTableRowViewModel>> LoadUsersAsync()
    {
        var users = await _userService.GetTableRowsAsync();
        return users
            .Select(user => new UserTableRowViewModel
            {
                Id = user.Id,
                Username = user.Username,
                Email = user.Email,
                Role = user.Role,
                Active = user.Active,
                CreatedUtc = user.CreatedUtc,
                InternalNotes = user.InternalNotes
            })
            .ToList();
    }
}

public sealed class EditUserInputModel
{
    public Guid Id { get; set; }
    public string Username { get; set; } = string.Empty;
    public string Email { get; set; } = string.Empty;
    public string Role { get; set; } = string.Empty;
    public bool Active { get; set; }
}

Section 5

Setup in a real ASP.NET Core app

The v1 wiring is intentionally small. You do not need extra infrastructure beyond the standard Razor Pages application shell.

  1. Add your tag helper namespace in Pages/_ViewImports.cshtml and Views/_ViewImports.cshtml with @addTagHelper *, MyApp.
  2. Place DataTableColumnAttribute.cs, DataTableTagHelper.cs, and ModalTagHelpers.cs under your project TagHelpers folder.
  3. Include DataTables CSS and JavaScript in your layout after Bootstrap and jQuery.
  4. Include wwwroot/js/app-ui.js after jQuery, Bootstrap, and DataTables.
  5. Include wwwroot/css/custom-bootstrap.css after Bootstrap so your component overrides win cleanly.
  6. Add one shared modal to layout using the modal tag helpers.
  7. Return the edit partial from an OnGetEditModalAsync handler and return JSON success from OnPostEditAsync.
Section 6

What this v1 intentionally does not solve yet

Keeping these out of v1 prevents premature abstraction and keeps the implementation small enough to understand at a glance.

Server-side DataTables processing

Deferred until row counts justify more complex query, sort, and paging coordination.

Permission-driven row actions

Row-level buttons and conditional commands are application-specific and should evolve outside the core v1 helper.

Reflection-based edit form generation

Explicit partials remain clearer and safer for production editing workflows.

AJAX row patching without refresh

A full in-place update model can be added later once the save contract stabilizes.

Nested property path support

Flattening view models is simpler for v1 and reduces reflection edge cases.

Export buttons and plugin extras

Advanced DataTables extensions should be layered on only after the base interaction pattern is stable.
