Getting Started

Razor UI Patterns is a static GitHub Pages site that demonstrates reusable UI patterns and maps each one to practical ASP.NET Core Razor Pages implementation guidance.

Local development

  1. Clone the repository and open it in VS Code.
  2. Serve the root folder using any static server.
  3. Open index.html and navigate patterns/docs.

Suggested commands

python -m http.server 8000
# or
npx http-server .

Repository layout philosophy

Patterns in patterns/, conceptual guidance in docs/, shared front-end assets in assets/, and .NET reference app content in examples/razor-reference/.
