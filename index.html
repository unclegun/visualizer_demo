Theme System Implementation

The navbar palette dropdown applies live theme colors by setting CSS variables on :root. The tone toggle switches between light and dark surface styles without changing the selected palette identity.

How It Works
  • Palette source: ./data/palettes.json contains JSON records with id, name, colors, and sourceUrl.
  • Palette UI: Search input filters available palettes; selecting one maps color tokens to CSS variables.
  • Tone mode: Light/Dark toggle adds or removes theme-dark class on body.
  • Persistence: Selected palette and tone are saved in localStorage and restored on load.
CSS Variable Mapping
:root {
    --theme-primary: #0d6efd;
    --theme-secondary: #0b5ed7;
    --theme-accent: #6ea8fe;
    --theme-surface: #f8f9fa;
    --theme-text-on-primary: #ffffff;
}

.navbar.bg-primary {
    background: linear-gradient(135deg, var(--theme-primary), var(--theme-secondary));
}
Client Integration Pattern
const palettes = await fetch('./data/palettes.json').then(r => r.json());

function applyPalette(palette) {
    document.documentElement.style.setProperty('--theme-primary', palette.colors[0]);
    document.documentElement.style.setProperty('--theme-secondary', palette.colors[1] ?? palette.colors[0]);
    document.documentElement.style.setProperty('--theme-accent', palette.colors[2] ?? palette.colors[0]);
    localStorage.setItem('selectedThemePalette', palette.id);
}

function applyTone(mode) {
    document.body.classList.toggle('theme-dark', mode === 'dark');
    localStorage.setItem('toneMode', mode);
}
Implementation Steps
  1. Create a palettes.json file with palette definitions.
  2. Add palette picker UI to your navbar with search input and apply button.
  3. Define theme CSS variables and consume them in key UI components.
  4. Initialize picker and toggle logic on DOMContentLoaded.
  5. Persist selected palette and tone in localStorage.

Apply Palette Function
function applyPalette(palette) {
    if (!palette || !Array.isArray(palette.colors)) return;

    const primary = palette.colors[0];
    const secondary = palette.colors[1] ?? palette.colors[0];
    const accent = palette.colors[2] ?? palette.colors[0];

    document.documentElement.style.setProperty('--theme-primary', primary);
    document.documentElement.style.setProperty('--theme-secondary', secondary);
    document.documentElement.style.setProperty('--theme-accent', accent);

    localStorage.setItem('selectedThemePalette', palette.id);
}
Tone Toggle Function
function applyTone(mode) {
    const normalized = mode === "dark" ? "dark" : "light";
    document.body.classList.toggle("theme-dark", normalized === "dark");
    localStorage.setItem("toneMode", normalized);
}

Minimum Required Fields
  • id - unique identifier
  • name - display name
  • colors - array of hex colors (min 4)
  • sourceUrl - link to palette source (optional)

Basic Chart Setup
const ctx = document.getElementById('myChart').getContext('2d');
new Chart(ctx, {
    type: 'bar',
    data: {
        labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May'],
        datasets: [{
            label: 'Sales',
            data: [12, 19, 3, 5, 2],
            backgroundColor: 'var(--theme-primary)',
            borderColor: 'var(--theme-primary)',
            borderWidth: 1
        }]
    },
    options: {
        responsive: true,
        maintainAspectRatio: true,
        plugins: {
            legend: { display: true, position: 'top' }
        }
    }
});

API Reference

Function Parameters Description
applyPalette(palette) palette: Object Applies a palette to the page by setting CSS variables
applyTone(mode) mode: 'light' | 'dark' Toggles between light and dark theme modes
filterPalettes(searchText) searchText: string Filters palettes by name, id, or color codes
loadPalettes() None Loads palettes from ./data/palettes.json
showSection(name, element) name: string, element: HTMLElement Shows a content section and updates navigation
filterCharts(type) type: string Filters dashboard cards by chart type
exportLayout() None Exports current dashboard layout as JSON
toggleGrid() None Shows/hides grid lines on dashboard
