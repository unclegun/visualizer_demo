Pattern: HTMX Cascading Selects

Parent selection fetches child options via server-rendered fragment swap.

Why use this in ASP.NET Core Razor Pages

Useful for admin forms where option validity is dynamic and should stay server-authoritative.

Live static demo

Refreshing options...

How it works

The parent control posts its value; handler returns only child option markup or option partial to swap into target select.

Copy-paste markup snippet

<select name="CountryId"
        hx-get="/Orders?handler=Cities"
        hx-target="#citySelect"
        hx-include="[name='CountryId']">
</select>

<select id="citySelect" name="CityId">
  <option value="">Select a country first</option>
</select>

Razor Pages handler example

public async Task<PartialViewResult> OnGetCitiesAsync(Guid countryId)
{
    var options = await _geo.GetCitiesAsync(countryId);
    return Partial("_CityOptions", options);
}

Partial view example

@model IReadOnlyList<SelectOptionVm>
<option value="">Choose a city</option>
@foreach (var city in Model)
{
  <option value="@city.Value">@city.Text</option>
}

Notes, tradeoffs, and best uses

  • Great for dependent controls and permissions-aware options.
  • Always validate selected child server-side on submit.
  • Return empty-state options intentionally.
Implementation checklist
  1. Render both selects in initial GET.
  2. Parent select sends current value via hx-include.
  3. Child options fragment is returned by handler.
  4. Server validates parent-child compatibility on final submit.
  5. Empty and unauthorized states return explicit option text.
Robust handler example
public async Task<PartialViewResult> OnGetCitiesAsync(Guid countryId)
{
    if (countryId == Guid.Empty)
        return Partial("_CityOptions", Array.Empty<SelectOptionVm>());

    var options = await _geo.GetCitiesAllowedForUserAsync(countryId, User);
    return Partial("_CityOptions", options);
}

Submit validation example

public async Task<IActionResult> OnPostAsync(EditOfficeVm input)
{
    var isValidPair = await _geo.IsCityInCountryAsync(input.CityId, input.CountryId);
    if (!isValidPair)
        ModelState.AddModelError(nameof(input.CityId), "Selected city is not valid for the chosen country.");

    if (!ModelState.IsValid)
        return Page();

    await _offices.SaveAsync(input);
    return RedirectToPage();
}
