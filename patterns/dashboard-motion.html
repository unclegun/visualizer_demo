Use in Razor Pages

  • Place motion orchestration in shared JS modules loaded from _Layout.cshtml.
  • Keep per-page metric definitions in strongly typed models and data attributes.
  • Use lower animation intensity for operations consoles with rapid live updates.
Vanilla JS Pattern 
document.querySelectorAll('[data-progress-value]').forEach((bar) => {
  const value = Number(bar.dataset.progressValue || 0);
  requestAnimationFrame(() => {
    bar.style.width = `${value}%`;
  });
});
