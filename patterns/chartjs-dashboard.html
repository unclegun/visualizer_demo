Pattern: Chart.js Dashboard

Reusable dashboard shell where chart composition, responsive layout, and palette-aware styling are treated as a repeatable pattern rather than product identity.

Why this matters in Razor Pages

It cleanly separates dashboard markup in Razor views, server-fed data in handlers or APIs, and lightweight client rendering in focused JavaScript modules.

How it works

  1. Razor Page loads shell cards and canvas placeholders.
  2. A page handler returns chart datasets as JSON.
  3. A focused chart renderer module initializes Chart.js instances once.
  4. Palette variables style both the page and chart datasets so the theme feels unified.
  5. Refresh is done by re-fetching JSON and replacing only chart instances, not the whole page.
PageModel Endpoint
public async Task<JsonResult> OnGetChartDataAsync(DateOnly from, DateOnly to)
{
    var vm = await _dashboardService.GetChartsAsync(from, to);
    return new JsonResult(vm);
}

Use query parameters to support filters and date windows without adding controller complexity.

Dashboard Markup
<section class="dashboard-grid">
  <article class="dashboard-chart-card">
    <h3 class="h6">Revenue Trend</h3>
    <canvas id="chart-revenueTrend"></canvas>
  </article>
</section>

Keep chart card markup explicit; only rendering logic should be abstracted.

Client Refresh Example
async function refreshDashboard(from, to) {
  const res = await fetch(`/Dashboard?handler=ChartData&from=${from}&to=${to}`);
  const data = await res.json();
  renderCharts(data);
}

document.querySelector("#applyFilters").addEventListener("click", () => {
  refreshDashboard("2026-01-01", "2026-03-31");
});
Best Practices
  • Destroy existing chart instances before re-rendering.
  • Use stable aspect ratios for predictable card heights.
  • Keep query shape versioned if multiple clients consume dashboard JSON.
  • Cache aggregate series on the server for expensive calculations.
Razor Mapping
public async Task<IActionResult> OnGetDashboardDataAsync()
{
    var summary = await _dashboardService.GetSummaryAsync();
    return new JsonResult(summary);
}

Handlers own data contracts while chart rendering stays in assets/js/charts.
