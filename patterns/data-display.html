Razor Pages adaptation

  • Place shell and state regions in the page markup.
  • Drive data from handler-based endpoints or postbacks.
  • Use partial updates for tbody and detail fragments.

Accessibility and performance

  • Keep row actions keyboard reachable, not hover-only.
  • Sticky headers should preserve contrast in all themes.
  • Batch updates to avoid row-level DOM churn on every filter keystroke.
