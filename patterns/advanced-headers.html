Pattern Category: Advanced Header / Hero

Technical Aurora Hero + Scientific Grid Hero

What it is: high-end section headers with layered motion. Problem solved: visually flat page starts that fail to communicate hierarchy and confidence.

A. Technical Aurora Hero

Mission-ready dashboard header with restrained motion

Fits internal dashboards and landing sections where clarity and trust matter more than visual noise.

B. Scientific Grid Hero

Technical framing for research and data-first applications

The line-grid + orbital motif supports scientific and analytical context without distracting from primary actions.

Where this fits in Razor Pages

  • Best for _Layout.cshtml and dashboard landing partials.
  • Use page-level variants for section intros in docs-heavy screens.
  • Keep animation intensity lower for dense admin tables.

Use vs avoid

  • Use when screen transitions need hierarchy and orientation cues.
  • Avoid in repetitive data-entry workflows where speed dominates.
  • Always keep core actions readable at 200% zoom and keyboard-only.
Razor + HTML 
<section class="hero-shell">
  <div class="hero-mesh" data-parallax-layer="0.03"></div>
  <div class="hero-band" data-parallax-layer="0.06"></div>
  <div class="hero-content">
    <h1>Telemetry Center</h1>
    <a class="btn btn-primary" asp-page="/Dashboard/Index">Open Dashboard</a>
  </div>
</section>

Accessibility / performance

Hero motion uses transform only, honors prefers-reduced-motion, and leaves content fully usable without animation.

Implementation notes

Keep the visual shell reusable in a shared partial and pass content through model properties for section-level reuse.
