Pattern: HTMX Modal Form

Open a Bootstrap modal shell, load form partial with hx-get, and submit with hx-post.

Why use this in ASP.NET Core Razor Pages

Modal edits stay explicit and maintainable: handlers return partials for both initial load and validation failures.

Live static demo

Loading modal partial...

How it works

The outer modal is static. HTMX loads and submits only the modal body region, keeping flow local and testable.

Copy-paste markup snippet

<button hx-get="/Users?handler=EditForm&id=42"
        hx-target="#modalBody"
        data-bs-toggle="modal"
        data-bs-target="#userModal">
  Edit user
</button>

<form hx-post="/Users?handler=Save"
      hx-target="#modalBody"
      hx-swap="innerHTML">
  ...
</form>

Razor Pages handler example

public async Task<PartialViewResult> OnGetEditFormAsync(int id)
{
    return Partial("_EditUserForm", await _users.GetEditVmAsync(id));
}

public async Task<IActionResult> OnPostSaveAsync(EditUserVm input)
{
    if (!ModelState.IsValid)
        return Partial("_EditUserForm", input);

    await _users.SaveAsync(input);
    return new EmptyResult();
}

Partial view example

@model EditUserVm
<div class="modal-body" id="modalBody">
  <label>Display Name</label>
  <input asp-for="DisplayName" class="form-control" />
  <span asp-validation-for="DisplayName" class="text-danger"></span>
</div>

Notes, tradeoffs, and best uses

  • Great fit for edit-in-place without full-page navigation.
  • Validation remains server-authoritative.
  • Use explicit form partials over generic reflection forms.
End-to-end request flow
  1. User clicks Edit and HTMX requests modal partial via hx-get.
  2. Server returns form HTML with validation spans and anti-forgery token.
  3. User submits with hx-post to save handler.
  4. On validation failure, server returns same partial with errors.
  5. On success, return 204 and close modal, then refresh target row/region.
Anti-forgery + form partial
@model EditUserVm
<form hx-post="/Users?handler=Save"
      hx-target="#modalBody"
      hx-swap="innerHTML">
  @Html.AntiForgeryToken()
  <input asp-for="DisplayName" class="form-control" />
  <span asp-validation-for="DisplayName" class="text-danger"></span>
  <button class="btn btn-primary mt-3" type="submit">Save</button>
</form>
Success signaling
public async Task<IActionResult> OnPostSaveAsync(EditUserVm input)
{
    if (!ModelState.IsValid)
        return Partial("_EditUserForm", input);

    await _users.SaveAsync(input);
    Response.Headers["HX-Trigger"] = "user-updated";
    return NoContent();
}
Client event hook
document.body.addEventListener("user-updated", () => {
  bootstrap.Modal.getInstance(document.getElementById("userModal"))?.hide();
  htmx.trigger("#usersTableBody", "refresh-users");
});

This keeps modal lifecycle logic tiny and explicit.
