CSS Only 
.accent-divider {
  height: 1px;
  background: linear-gradient(90deg, transparent, var(--theme-primary), transparent);
}

.focus-frame {
  border: 1px solid color-mix(in srgb, var(--theme-accent) 26%, var(--line-soft));
  box-shadow: var(--accent-glow);
}

Razor Pages adaptation

  • Best in shared section partials and dashboard modules.
  • Good for public landing headers and executive summary blocks.
