Pattern Category: Navigation / Layout Interactions

E. Adaptive Sticky Navbar + F. Premium Filter Bar

What it is: state-aware navigation and sticky utility surfaces. Problem solved: orientation loss and filter fatigue in long data-heavy pages.

Section-aware nav highlighting

This page demonstrates nav section grouping with data-nav-section, so every Advanced UI page lights the same top-level nav tab.

Best fit in Razor Pages

Put adaptive navbar behavior in _Layout.cshtml and feed section metadata via ViewData so active state stays accurate.

When not to use

Avoid sticky filter bars on short forms or pages where sticky surfaces reduce usable viewport area.

Layout Snippet 
@* _Layout.cshtml *@
<body data-nav-section="@ViewData["NavSection"]">
  <nav class="navbar site-navbar sticky-top">...</nav>
  <div class="scroll-progress"><span data-scroll-progress></span></div>
  @RenderBody()
</body>
